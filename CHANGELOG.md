# Changelog

## Visual design pack — 2026-11-14

Four original labelled AI concept boards, primary Horizon Zero Dawn / No Man’s Sky research, Babylon art-to-world guide and required next goals for human/robot animations and Cometa, an astronaut dachshund. ## 0.2.0 — 2026-11-14

First independent demo implementation: modular Babylon world, five finite regions, eight original local GLBs, PIP/Scout, movement and camera, deterministic resource simulation, Earth-to-Moon loop, ice/crops/storm, save/checkpoint, science journal and report. Bundled 13 agent skills with licenses, integrity lock and Gemini batch handoff. Six reference games now map to original scoped design pillars. Browser/GPU acceptance remains pending.
