## Required record for future implementation

Maintain one row per AI-assisted material in the source/asset manifests:

| Field | Required record |
|---|---|
| ID/path | Exact distributed file and its source file |
| Tool/model/date | What was used and when |
| Role | Code assistance, image generation, text, audio, data transformation or other |
| Human review | Reviewer, scope and concrete corrections |
| Rights/source | Original inputs, applicable terms, third-party notices and redistribution status |
| Label | Visible AI identification for generated images/videos under the cited guidance; descriptive text/metadata for audio/code/data |
| Scientific classification | Observation, model assumption, artistic interpretation or fiction |
| Competition provenance | Pre-event, event-window or later work; organizer clarification if necessary |

Do not remove provenance or watermarking. A hidden metadata tag alone does not satisfy the visible label described for generated media. Do not apply a false “AI generated” label to genuine NASA measurements or photographs; label the generated composition or derivative appropriately. No NASA marks, flags or mission identifiers should be introduced into generated imagery.
